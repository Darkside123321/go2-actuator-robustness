# 工程设计与验收口径

## 要解决的问题

目标速度控制策略可能依赖训练时的关节伺服响应。这个扩展项目将关节
PD 参数误差和策略动作执行延迟做成可配置条件，给出失败边界与控制代价。

## 已有组件与新增工作

- 宇树原仓库：机器人模型、任务、奖励、PPO 网络和训练入口。
- Mjlab：PD 随机化原语、观测历史和 GPU 物理后端。
- 本项目：控制周期动作 FIFO、场景组合、固定命令评估、首次失败记账、
  真实速度 RMSE、资源/版本记录、结果导出与工程验收。
- 不把启用框架已有功能称为原创学习算法。

## 改动位置

动作 FIFO 位于策略输出与目标角度缩放之间。策略仍输出 12 维动作；
每个环境的一组 12 维命令使用同一延迟，延迟在重置时采样，在本次
episode 内保持不变。队列启动与局部重置时为中性动作，表示默认站姿。
这是离散整控制周期的执行延迟模型，不是完整实机通信/电机电气模型。

DR 配置：PD 增益按默认值独立缩放至 [0.75,1.25]，策略动作延迟在
0、1、2 控制步之间采样。保留官方训练时已有的其他随机化。

History 配置：上述 DR 加 4 帧 actor 观测，由官方历史管理器提供，
actor 输入从 47 到 188；critic 保持 74。隐藏层 512/256/128、奖励与 PPO
参数不变。历史包含当前和过去 3 帧，在 50 Hz 下覆盖 60 ms。

## 评估协议

16 个随机初始状态，种子 2026。先站立 2 秒，再前进、横移、转向，
总时长 12 秒。命令通过 step event 更新，与下一次观测对齐，不使用
临时人为操作改变评估结果。初始 yaw ±0.1 rad，关节偏移 ±0.02 rad；
评估无训练噪声/质量/摩擦/质心随机化和速度冲击事件。

六个预设条件：标称、较软 PD、较硬 PD、20 ms 延迟、40 ms 延迟、
较软 PD +40 ms 延迟。改变增益时同时修改 MuJoCo 的 gain/bias 对应项，
通过官方 pd_gains 函数分配每环境模型字段。

评估中关闭框架自动 episode 终止，独立记录首次失败：机体高度
低于 0.14 m 或倾斜超过 70 度。失败后不再得分，不通过自动重置重获
机会。这里的完成率只表示在该明确定义下存活到结束，不代表满足所有
实机安全条件或每段命令精度要求。

跟踪 RMSE 从 2 秒之后计到首次失败（含失败步），同时报告样本覆盖率，
避免提前失败得到低 RMSE 被误读为好策略。失败在 warmup 内的 episode
没有跟踪成绩，数值为 null。力矩为执行器空间统计；机械绝对功由匹配的
广义驱动力与广义速度求和，再按控制周期积分，不能称作电池耗电。

trace.csv 的均值明确包括全部环境（含已失败者），用于排查现象；
正式得分来自逐环境存活掩码。不能拿全环境轨迹均值替代评分。

## 验收目标

configs/acceptance.json 在扩展策略训练完成前固定：
标称完成 16/16 且 XY RMSE <=0.20 m/s；40 ms 完成至少 14/16；
较软 PD+40 ms 完成至少 14/16。
这只是当前有限工况的工程目标，不是行业标准或统计置信结论。

固定一个训练种子、相同训练预算，先检查集成方案是否有工程价值。
如后续要报告跨随机种子优势或扩大工作范围，应增加对应验证，而不把
本轮单种子结果推广成普遍结论。

## 一键命令

从仓库根目录，使用原 go2rl 环境：

```bash
python -m unittest discover -s tests
python -m go2_robust.train --variant dr --iterations 1500 --num-envs 256 --seed 42
python -m go2_robust.train --variant history --iterations 1500 --num-envs 256 --seed 42
python -m go2_robust.evaluate --variant history --checkpoint "$CHECKPOINT" --output results/history_s42
python -m go2_robust.report
```

CHECKPOINT 应为实际训练 status.json 中 run_dirs 下的 model_1499.pt。
evaluation 拒绝覆盖已有结果目录。训练命令会启动实际训练，请勿为了
查看模型重复运行。原始模型与日志保留在 runs/results，发布仓库只收录
reports 中的小型指标、图和校验信息。

## 指标精确定义

速度命令和实测速度均在机体坐标系内。XY RMSE 定义为
sqrt(mean((vx-vx_cmd)^2+(vy-vy_cmd)^2))，单位 m/s；不再除以轴数 2。
转向 RMSE 为 sqrt(mean((wz-wz_cmd)^2))，单位 rad/s。
动作变化 RMS 使用发出的原始 12 维策略动作差值，属于无量纲控制变化指标。
力矩 RMS 在执行器通道与有效控制步上取均方根；机械功率由广义坐标中
匹配的 qfrc_actuator 和 qvel 相乘，避免执行器分组顺序与关节顺序不一致。
