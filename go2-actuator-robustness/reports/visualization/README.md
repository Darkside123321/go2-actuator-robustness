# Go2 工程可视化总览

统一样式：闭合四边框、刻度朝内、Arial Bold、粗线条和固定配色；纯白背景、无网格，曲线全部为实线。
图中保留坐标轴标签与图例，图下不放说明段落。以下说明独立于图片。

| 图 | 看什么 | 核心读法 |
| --- | --- | --- |
| 01_robustness_overview | 六工况完成率与跟踪误差 | 四种策略完整对照；误差与完成率一起看；微调版额外训练 500 轮 |
| 02_velocity_response | 前进、横移、转向的目标与实际速度 | 黑实线为目标；看加速、切换和持续运动时的偏差 |
| 03_error_localization | 过渡/稳态误差与平均稳态速度 | 前进改善明显，横移仍有欠速，不以总体分数掩盖单项问题 |
| 04_state_and_control | 高度、倾角、关节目标误差、力矩、机械功率和机械功 | 同时看控制效果和代价；机械功不能称为电池耗电 |
| 05_training_progress | 三组初始训练及追加微调 | 微调使用独立追加迭代轴；奖励来自不同训练条件，不直接代表测试排名 |

速度和状态主曲线汇总 16 个配对初始状态，半透明带为初始状态的 P10–P90 范围，
不是多训练种子的置信区间。全部 28,800 条标称逐时刻记录参与汇总。
历史版没有保存逐环境标称时序，因此保留在鲁棒性总览和训练图中，不虚构其时序。

源数据与映射见 source_data/、data_contract.json；完整英文图注见
../../docs/VISUALIZATION_CAPTIONS.md。模型、环境与奖励均未在本次绘图中改动。

复现：在原 go2rl 环境中，从仓库根目录运行 python -m go2_robust.visualize。
导出为 PNG（300 dpi）、SVG、PDF 和 TIFF（600 dpi）。
